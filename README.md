# Aethra — Ateliê de mundos

Um espaço para criar universos de fantasia, organizar referências e desenvolver histórias.

[Abrir o Aethra](https://lad1ambr0sya-web.github.io/aethra-worldbuilding/)

## O que você pode criar

- Universos independentes com temas e abas personalizáveis.
- Notas, documentos e pastas com editor de texto formatado.
- Personagens com fichas e cartas personalizáveis.
- Bestiário, tramas, cenas e referências de escrita.
- Mapas com pinagens e um globo 3D interativo.
- Conexões entre elementos do mundo, calendários e linhas do tempo.
- Metas de escrita e atalhos para continuar seu trabalho.
- Playlists com links do YouTube e músicas importadas.

## Acesso

O acesso é feito com uma conta fornecida pela administração. O cadastro público não está disponível. Cada conta possui seu próprio espaço de criação.

## Uso e compatibilidade

Use um navegador atualizado. O globo 3D requer suporte a WebGL. Para melhores resultados no globo, prefira mapas equiretangulares com proporção 2:1.

Mantenha cópias de segurança dos seus mundos usando a exportação do aplicativo. Arquivos de música importados ficam no dispositivo em que foram adicionados.

## Sobre o projeto

O Aethra é desenvolvido com HTML, CSS e JavaScript, com foco em uma experiência de escrita simples e visual. Os exemplos de mundos e personagens são fictícios e editáveis.
