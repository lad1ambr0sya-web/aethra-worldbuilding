# Contas do Aethra

O Aethra está disponível para pessoas com uma conta fornecida pela administração.

- Entre no aplicativo com o e-mail e a senha recebidos em particular.
- O cadastro público está desativado.
- Cada conta possui seus próprios universos e conteúdos.
- Para solicitar acesso ou ajuda com a conta, fale com a pessoa responsável pelo projeto.

Não publique senhas nem compartilhe suas credenciais no repositório.
